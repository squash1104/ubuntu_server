Visão Geral do Sistema

O SisAps é um sistema web desenvolvido em Django 5.2 para gerenciamento e fidelização de apoiadores políticos. O sistema oferece funcionalidades completas de cadastro, monitoramento, comunicação e análise de dados, com dashboards interativos, mapas de calor e relatórios exportáveis.

Arquitetura

FrameworkDjango 5.2.4 + Daphne (ASGI)
Banco de DadosPostgreSQL
FrontendBootstrap 5, Chart.js, Leaflet.js
ComunicaçãoTwilio SMS + WhatsApp Cloud API (Meta)
WebSocketsDjango Channels 4 (atualizações em tempo real)
AutenticaçãoDjango Auth + rate limiting + idle timeout
