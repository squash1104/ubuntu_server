🚀 Como Usar

  1. Clique no botão 💬 no canto inferior direito
  2. Selecione um contato da lista de usuários online
  3. Digite sua mensagem e pressione Enter ou clique em ➤
  4. Minimize com ➖ ou feche com ✕
  5. Arraste a janela para reposicionar
  6. Redimensione usando o canto inferior direito

💡 Recursos Técnicos

  • 🔧 CSS Moderno: Flexbox, Grid, CSS Variables
  • 🎨 Glassmorphism: Efeitos de vidro com backdrop-filter
  • 📱 Mobile First: Design responsivo com breakpoints
  • ⚡ Performance: Animações otimizadas com CSS transforms
  • 🌙 Dark Mode: Detecção automática do tema do sistema
  • ♿ Acessibilidade: Suporte a navegação por teclado

🎯 Benefícios para o Usuário

  • 👁️ Menos intrusivo: Ocupa menos espaço na tela
  • 🎨 Visual atrativo: Interface moderna e profissional
  • 📱 Multiplataforma: Funciona perfeitamente em todos os dispositivos
  • ⚡ Mais rápido: Animações suaves e responsivas
  • 🌙 Conforto visual: Adapta-se ao tema preferido do usuário
